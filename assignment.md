Assignment 3.5 — Blog / Portfolio Mini-Project

What to build: A personal blog or portfolio website.

Required sections:

* Header with name/logo
* Navigation bar
* About Me
* Skills or Interests
* Blog posts or projects
* Images
* Useful links
* Footer with contact details

Rules:

1. Use links, images, and lists in HTML.
2. Use semantic tags.
3. Navigation links must be working.
4. Code must be clean and properly indented.
5. You can divide the website into multiple HTML files.

Submission: Complete blog/portfolio project, source code, and GitHub repository link.
